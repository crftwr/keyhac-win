# Keyhac for Windows

> [!WARNING]
> **This repository has been retired and archived.**
>
> Keyhac for Windows and Keyhac for macOS have been unified into **Keyhac v2** — a single Python codebase that runs on both OSes. Development continues at:
>
> **https://github.com/crftwr/keyhac**
>
> This repository (Keyhac for Windows, up to v1.83) is kept as a read-only reference. Existing `config.py` files need migration to the new API — see the [migration guide](https://github.com/crftwr/keyhac/blob/main/doc/migration-from-keyhac-win.md).

> [!WARNING]
> **このリポジトリは開発を終了し、アーカイブされました。**
>
> Windows 版と macOS 版の Keyhac は、両 OS で動作する単一の Python コードベース **Keyhac v2** に統合されました。開発は以下で継続します。
>
> **https://github.com/crftwr/keyhac**
>
> このリポジトリ (Keyhac for Windows, v1.83 まで) は読み取り専用の参照用として残されています。既存の `config.py` は新しい API への移行が必要です。[移行ガイド](https://github.com/crftwr/keyhac/blob/main/doc/migration-from-keyhac-win.md)を参照してください。
